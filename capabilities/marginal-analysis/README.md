# Marginal analysis

A reusable capability for comparing the incremental value, cost, and risk of
business decisions. The workbook is the quantitative model; the specification
defines the intended inputs and interpretation.

## Files

- `spec.md` — scope, assumptions, inputs, and outputs
- `model.xlsx` — workbook model

Exercised in: perfect-competition (Stage 1.2) — see `docs/briefs/perfect-competition-brief.md`
